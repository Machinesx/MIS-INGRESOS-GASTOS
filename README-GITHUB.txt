MIS INGRESOS Y GASTOS - PWA PARA GITHUB PAGES

IMPORTANTE
Sube TODOS estos archivos a la RAIZ del repositorio de GitHub Pages:
- index.html
- manifest.json
- sw.js
- .nojekyll
- icons/icon-192.png
- icons/icon-512.png

La URL configurada para la PWA es:
https://machinesx.github.io/MIS-INGRESOS-GASTOS/

Después de subir los archivos:
1. Espera a que GitHub Pages termine de publicar.
2. Abre la URL anterior en Chrome Android.
3. Si ya habías abierto una versión anterior, recarga la página y, si fuera necesario, borra los datos del sitio para que Chrome vuelva a leer el manifest y el service worker.
4. En Chrome, menú ⋮, busca "Instalar aplicación" o "Añadir a pantalla de inicio".

Los datos de la aplicación se guardan localmente en el navegador del dispositivo. No se suben a GitHub.
