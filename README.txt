MIS INGRESOS Y GASTOS
======================

Aplicación web progresiva (PWA) para GitHub Pages.

ARCHIVOS
- index.html        Aplicación completa
- manifest.json     Configuración instalable
- sw.js             Funcionamiento offline
- icons/            Iconos de la aplicación

PUBLICACIÓN EN GITHUB PAGES
1. Sube TODOS estos archivos a la raíz del repositorio.
2. El archivo principal debe llamarse exactamente index.html.
3. En GitHub: Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: la rama que uses (normalmente main o principal).
6. Folder: / (root).
7. Guarda y abre la URL que GitHub muestre.

INSTALACIÓN EN ANDROID
Abre la web publicada en Chrome. Usa el menú del navegador y selecciona
“Añadir a pantalla de inicio” o “Instalar aplicación”, según aparezca.

DATOS
Los datos se guardan únicamente en el almacenamiento local del navegador.
No se envían a GitHub ni a un servidor. Usa “Copia completa JSON” para
hacer copias de seguridad y trasladar los datos a otro dispositivo.

IMPORTANTE
Si cambias la URL, navegador o dispositivo, la información local no se
traslada automáticamente. Restaura la copia JSON en la nueva instalación.
